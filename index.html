Respaldo en GitHub

Guarda catálogo, configuración e historial en el archivo datos/respaldo.json del repositorio. Con el token configurado, el respaldo se hace solo cada vez que generas una cotización.

⚠️ El repositorio es público: cualquiera podría ver el respaldo (incluye nombres y teléfonos de tus clientes).

¿Cómo creo el token? (una sola vez)
  1. Abre github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: cotizador. Vencimiento: el máximo que te ofrezca.
  3. En Repository access elige Only select repositories → Karate.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Genera el token, cópialo y pégalo aquí. Queda guardado solo en este teléfono (nunca viaja en el respaldo).

Copia en archivo (sin token)

Alternativa manual: descarga un archivo con todos tus datos y guárdalo donde quieras (Drive, correo, etc.).
